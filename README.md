### 🌟 Featured Projects

* **[wpfy](https://github.com/wpfyorg/wpfy)** *(Python)*: Docker-first WordPress and server management suite. Simplifies container orchestration, automated deployments, and reproducible server environments for high-traffic WordPress stacks.

* **[openstream-tv](https://github.com/wpfyorg/openstream-tv)** *(Rust)*: High-performance multi-provider IPTV server ported from Go to Rust. Handles live streams, catch-up, EPG parsing, and on-demand playback under tight CPU and memory constraints.

* **[idu-unlock](https://github.com/wpfyorg/idu-unlock)** *(Python)*: Hardware penetration testing and vulnerability research toolkit. Exploits command-injection flaws on locked carrier CPE routers to gain persistent root SSH, dump flash partitions, and automate OpenWrt deployment.

* **[openwrt-jiotv-go](https://github.com/wpfyorg/openwrt-jiotv-go)** *(Shell / UCI)*: OpenWrt service wrapper with procd process supervision, crash recovery, RAM-backed EPG caching, and secure remote routing through Cloudflare Tunnels.

* **[waaree-solar-dashboard](https://github.com/wpfyorg/waaree-solar-dashboard)** *(TypeScript)*: Self-hosted solar telemetry dashboard for WAAREE PV Hub / FoxESS systems. A progressive web app on Cloudflare Workers with live generation stats, weather forecasts, and power-cut detection.

* **[car-launcher](https://github.com/wpfyorg/car-launcher)** *(Kotlin)*: Landscape-first Android launcher for automotive aftermarket head units, with driver-friendly touch targets, glanceable metrics, and lightweight performance.
